常见问题

在哪里创建 API Key？

登录后进入「令牌」创建密钥。为不同设备分别创建密钥，便于撤销。

怎样核对模型价格？

在模型广场选择可用分组，查看计费详情中的币种、输入和输出单价或按次价格。实际费用可在用量日志核对。

客户端可以使用哪些模型？

模型需同时支持客户端请求的协议，并在当前令牌分组内开放。配置步骤见对应客户端文档。

如何查看一次请求的费用？

登录控制台，在用量日志中按调用时间和模型查找对应记录。
